# Подключение МоегоСклада

Первая фаза синхронизации безопасна: сайт читает список складов, но не создаёт и не изменяет товары, цены, остатки или заказы в МоемСкладе.

1. Создайте отдельный токен доступа для сайта в аккаунте МоегоСклада.
2. В настройках окружения приложения Timeweb добавьте `MOYSKLAD_ACCESS_TOKEN` со значением этого токена. Не сохраняйте его в админке, файлах проекта или Git.
3. Перезапустите приложение и выполните в консоли Timeweb:

   ```bash
   python3 manage.py moysklad_check
   ```

Команда выведет названия складов и их ID. Их нужно указать в админке сайта в карточках «Магазины»: Екатеринбург и Ярославль. Только после этого подключается следующая фаза: сопоставление карточек товаров, чтение остатков и цен.

До появления подтверждённых сопоставлений витрина, корзина и оформление заказа продолжают работать по текущим данным сайта.

## Первый импорт без риска

Для связи Екатеринбурга с актуальным складом выполните:

```bash
python3 manage.py moysklad_bind_store ekaterinburg "Основной склад"
```

Затем посмотрите первые 100 позиций учёта и их цены:

```bash
python3 manage.py moysklad_catalog_preview
```

Обе команды читают данные и не создают, не удаляют и не меняют объекты в МоемСкладе. По этому списку карточки сайта будут сопоставлены с конкретными товарами или модификациями, после чего включается обновление цен и остатков.
